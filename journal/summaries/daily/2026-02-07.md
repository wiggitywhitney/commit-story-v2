## Key Decisions

- **Restore Rich Library Requirement Objects** — Expanded library requirement tracking to include package and import names, enabling more deterministic SDK initialization and providing richer context for library discovery.

- **Priority-Based Instrumentation Hierarchy** — Replaced hardcoded span caps with a 4-tier instrumentation priority system, added span category tracking in result structure, and introduced a ~20% function instrumentation backstop.

- **Configurable Review Sensitivity** — Replaced hardcoded span run limits with review sensitivity modes (strict, moderate, off) to control PR summary annotations.

- **Dry Run Semantics** — Agents run normally and write files, but the Coordinator reverts all file changes from snapshots instead of committing them, preserving results while preventing persistent modifications.

- **improved Result Tracking** — Added `total_functions_in_file` to `span_categories` to enable ratio-based backstop calculation and provide the denominator for function instrumentation analysis.

- **Add Validation Complete Callback** — Introduced `onValidationComplete` to the `CoordinatorCallbacks` interface for symmetry with other callback methods.

- **File Exclude Patterns** — Added configurable glob patterns to skip file processing, with SDK init file and test files excluded by default.

- **Per-File Agent Notes** — Created optional `notes` field in FileResult interface to allow agents to explain judgment calls and provide context.

- **Schema Hash Tracking** — Added `schemaHashBefore` and `schemaHashAfter` fields to enable tracing of schema changes across file processing.

- **Agent Version Tagging** — Created `agentVersion` field in FileResult interface to track which agent/prompt version produced each result.

- **Move CLI and GitHub Action to PoC Scope** — Promoted CLI and GitHub Action from future to current scope with defined architectural constraints.

- **Progress Callbacks** — Defined `CoordinatorCallbacks` interface to enable interface-agnostic progress reporting.

- **Config Validation** — Added runtime config validation mechanism using Zod to catch configuration errors early.

- **Integrate Weaver Registry Diff Command** — Added registry diff command to CLI toolset for schema tracking, supporting multiple output formats (ANSI, JSON, markdown) and enabling programmatic detection of schema extensions and enforcement of "extend only" rules.

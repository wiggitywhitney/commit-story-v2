## Key Decisions

- **Testing Framework for Autonomous Development**: Use Vitest with 80% coverage threshold, supporting Node.js and TypeScript out of the box.
- **Claude Code Hooks Architecture**: Configure hooks in `.claude/settings.json` to run type checking, linting, and test suites at various development stages.
- **Simplify System Noise Filtering**: Replace specific regex patterns with a blanket filter for messages starting with `<` to catch all XML-style system tags.
- **Dynamic Implementation Guidance for Technical Decisions**: Analyze commit diffs to categorize files and generate context-specific instructions for decision classification, providing concrete anchors instead of vague guidance.
- **Consolidate Substantial Chat Check**: Move substantial message detection entirely into the message filter module to avoid multiple passes over messages and centralize all filtering logic.
- **Remove Technical Decision Content Verification**: Trust AI extraction while maintaining Zod schema validation to ensure correct structure. Word-matching verification was too strict and filtered out valid paraphrased reasoning.
- **Two-Agent Telemetry Architecture**: Use a deterministic Coordinator for mechanical tasks and a separate Instrumentation Agent for intelligent code transformation.
- **Telemetry Instrumentation Strategy**: Prioritize auto-instrumentation libraries over manual spans; add manual spans only for business logic not covered by libraries.
- **Telemetry Validation Approach**: Implement multi-step validation (syntax, linting, Weaver schema, tests) rather than relying on a single check.
- **Partial Success Model for Telemetry PoC**: Commit successfully-instrumented files and skip failed ones with clear reporting, rather than rolling back, to enable faster learning.

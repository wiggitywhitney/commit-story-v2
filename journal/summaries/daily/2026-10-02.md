## Key Decisions

- **Instrumentation scope**: Wrap async functions and I/O operations with OpenTelemetry spans; skip pure synchronous utilities that don't perform I/O or make external calls.
- **Error handling preservation**: Keep existing error handling patterns intact rather than restructuring code; let graceful catches for expected conditions remain silent while recording unexpected exceptions on spans.
- **Attribute data quality**: Sanitize file paths to filenames only (not full paths) when recording as span attributes to avoid leaking filesystem information.
- **Schema extension**: Register new span definitions and attributes in the semantic conventions schema as instrumentation is added, ensuring the schema stays in sync with the code.

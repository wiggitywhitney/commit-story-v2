# Weekly Summary — 2026-W28

## Week in Review

The developer spent the week fixing data integrity and observability issues in the commit-story journaling system. On Wednesday, they tackled a cascade of interconnected problems: environment variables were leaking from Claude Code into post-commit hooks, causing silent LLM failures that left behind placeholder text instead of real summaries. The fix involved stripping the offending Datadog gateway variables across all three hook invocation paths and reinstalling the corrected hook across nine repositories. While addressing that, they discovered stale placeholder files were blocking regeneration attempts, so they built a shared placeholder-detection helper and wired it into eight call sites to allow retries. They also found that the dialogue-extraction prompt was too aggressive—it was discarding quotes that overlapped with summary content when they should've been kept as supporting evidence. The prompt got clarified, the placeholder detection tightened to avoid false positives on casual mentions of "generation failed" in prose, and a data-loss window in the journal-manager code was eliminated by combining two separate writes into one. Finally, they added token usage metadata capture to all six LLM invoke call sites so the metrics would actually be observable downstream.

On Thursday, the developer debugged why telemetry had stopped flowing around July 6th and discovered it wasn't a code issue—the local OpenTelemetry Collector had simply stopped running after a machine restart. With that mystery solved, they addressed the underlying problem: the instrumentation had no guarantee that three critical attributes would actually be included in spans, even though the Spinybacked Orbweaver dashboard depends on them. The developer promoted these attributes from recommended to required in the telemetry schema, establishing a durable contract for future instrumentation runs. They also fixed a broken symlink in `node_modules` that was pointing to local source code, and updated PROGRESS.md to document the work.

## Highlights

- Fixed environment variable leakage causing silent LLM failures in post-commit hooks across nine repositories.
- Resolved a cascade of data integrity issues: stale placeholders blocking regeneration, overly aggressive dialogue filtering, and a data-loss window in journal-manager writes.
- Promoted three critical telemetry attributes from recommended to required status, ensuring downstream dashboard reliability.

## Patterns

- The week revealed interconnected failure modes in the journaling system—fixing one issue (placeholder dedup) exposed others (dialogue filtering, data-loss windows)—suggesting the system could benefit from more integrated testing of the full pipeline.
- Observability gaps (missing token usage metadata, unclear telemetry contracts) made debugging harder than necessary; promoting attributes to required status reflects a shift toward treating observability as a contract rather than a nice-to-have.
